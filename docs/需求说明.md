> 相关文档：[路线图](路线图.md)　[架构设计](架构设计.md)　[详细设计](详细设计.md)　[打包发布](打包发布.md)

## 1. 项目概述

一个跨平台（macOS / Windows）的 Markdown 所见即所得编辑器，交互对标 Typora：
单栏编辑、语法符号在光标离开后隐藏、支持 Mermaid 图表的实时渲染。

- 产品名称：TMD（Type Markdown, Done.）
- 目标用户：需要写带图表的 Markdown 文档的个人用户（开发者、学生、文档作者）
- 核心差异化：Mermaid 实时渲染体验流畅，中文输入体验一流

## 2. 技术栈（已确定）

| 层 | 选型 |
|---|---|
| 桌面壳 | Electron |
| 语言 | TypeScript |
| 构建 | Vite + electron-builder |
| 编辑器内核 | Milkdown（ProseMirror） |
| 源码块编辑 | CodeMirror 6 |
| 图表 | Mermaid（npm，懒加载） |
| 数学公式 | KaTeX |
| IDE | VS Code |

## 3. 功能需求与版本划分

### v0.1（MVP：内核验证版，纯网页，先不套 Electron 壳）

目标：验证编辑器手感与 Mermaid 渲染，跑通核心体验。**（已完成，2026-09-06）**

- [x] 编辑区：单栏所见即所得编辑
- [x] 基础语法渲染：标题、粗体/斜体/删除线、行内代码、链接、引用、有序/无序列表、任务列表、分隔线
- [x] 代码块：语法高亮（refractor/prism，常用语言）
- [x] **Mermaid 代码块实时渲染**（核心）：输入防抖 300ms、语法错误时清空旧图并显示错误信息（与 Typora/Obsidian 一致）、SVG 缓存、点击图进入源码编辑
- [x] 图片：`![]()` 语法渲染、粘贴图片插入（data URL，>5MB 忽略）
- [x] 表格：GFM 表格编辑
- [x] 深色/浅色主题切换（Mermaid 主题联动）
- [x] 文件打开/保存（浏览器：导入/下载；Electron：原生对话框，见 v1.0 进展）

明确不做：登录、云同步、协作、移动端。

目标：套上 Electron 壳，成为真正能用的桌面软件。**（功能开发完成，2026-09-06；Mac 打包链路已验证，Windows nsis 待实测）**

- [x] Electron 壳 + 本地文件读写（打开/保存/另存为原生对话框，Cmd/Ctrl+O/S 快捷键，标题栏脏标记）
- [x] 本地文件系统：最近文件（侧边栏）、未保存关闭确认
- [x] 文件树侧边栏（打开文件夹，两层展开）、标签页多文件（Cmd/Ctrl+T / W）
- [x] 源码模式（CodeMirror 6，Cmd/Ctrl+E 切换，自带搜索）
- [x] 导出：HTML（mermaid/katex 走 CDN 的独立文件）、PDF（系统打印对话框）、Word（.docx 原生可编辑，标题/列表/表格/超链接均为原生元素）、长图（单张 PNG，物理清晰度不低于 2x）
- [x] 数学公式（KaTeX，$行内$ 与 $$块级$$）
- [x] 查找替换（所见即所得模式：高亮全部匹配 + 计数跳转 + 单个/全部替换；源码模式用 CodeMirror 自带搜索）
- [x] 大纲面板（标题导航，1-3 级）+ 字数统计
- [x] 自动保存到文件（菜单开关，默认关闭，开启后每 5 秒写回）
- [x] 设置面板（主题切换、自动保存开关、图片存储策略、语言切换）
- [x] 多语言界面（中文/英文，默认跟随系统语言）
- [x] 粘贴图片双存储策略（inline data URL / 文档同目录 assets/ 相对路径，未保存或落盘失败自动降级 inline）
- [x] 任务列表复选框点击切换（ProseMirror 事务驱动，可 Cmd+Z 撤销）
- [x] 目录块（TOC）：`<!-- TOC -->` 区间自动生成 1-3 级标题目录，标题变化自动刷新，点击跳转（与大纲同源）
- [x] 应用图标（`build/icon.icns` / `icon.ico` / `icon.png`，蓝底 TMD + ↓ 设计，SVG 源文件 `build/icon.svg`）
- [x] Windows 界面适配：自绘标题栏（与 Mac 左右镜像、单行布局）、隐藏菜单栏、主题防闪（FOUC）、深浅主题跟随
- [ ] Mac / Windows 打包收尾：Mac 打包链路已就绪（图标已验证注入 .app）；CI 已配置双平台打包（tag 触发 release.yml，产出 Windows exe），Windows 实机安装体验待验证
- [x] 脚注、YAML front-matter 显示 → 已于 v1.x 完成（见下方语法扩展条目）

- [x] 自动更新（electron-updater 双源：Gitee 国内默认 + GitHub 备用，发现新版本弹窗问用户是否下载，设置面板可开关启动时自动检查；详见 [打包发布.md](./打包发布.md) §6.5 / §7）
- [x] 主题预设（简约白 / 深色 / 羊皮纸 / 护眼绿）+ 设置面板自定义 CSS 注入 + 文件式主题目录 `~/.tmd/themes/*.css`（文件名即主题名，设置面板打开目录/刷新加载，首次打开写入示例主题）
- [x] 最近文件管理增强：侧边栏行 hover × 单条移除、副标题旁一键清空（二次确认）；主菜单「打开最近文件」子菜单 + 系统最近文档（Windows Jump List / macOS Dock）注册与同步清空
- [x] 多文件夹工作区：文件侧边栏可同时挂载多个文件夹（追加去重、相互独立展开），行内 × 单条移除与一键清空均只取消挂载不删磁盘文件；挂载列表持久化，重启恢复并折叠，首次展开懒加载目录树
- [x] 侧边栏宽度可调：侧边栏与编辑区之间新增可拖拽分隔条（悬停高亮，宽度范围 180–480px 并自动持久化）；双击分隔条恢复默认 250px，窗口收窄时自动钳制保住编辑区最小宽度
- [x] 标签页右键菜单：标签上右键弹出「关闭标签页 / 关闭其他 / 关闭左侧 / 关闭右侧 / 关闭已保存的标签页 / 关闭所有标签页」，按右键位置与标签状态就地置灰不可用项（可用性/关闭目标为纯函数，可单测）；批量关闭整批只确认一次（含未保存标签时按数量确认，同意后全部丢弃），「关闭已保存」只关干净标签零风险；激活链路与单标签关闭一致（锚点幸存优先激活、全关时桌面关窗口/浏览器回空白页）
- [x] 拼写检查开关：设置面板「编辑器」分类新增开关，默认关闭（Chromium 对可编辑内容默认开启拼写检查且内置词典仅英语，专有名词/拼音/路径被画红色波浪线，中文虽不检查但英文词的误报刺眼）；开关持久化到 `tmd:spellcheck`，应用为编辑区容器 `#panes` 的 spellcheck 属性——ProseMirror/CodeMirror 动态可编辑根经属性继承获得，切换即时生效无需重建编辑器；boot 时与行号开关同点恢复
- [x] 语法扩展：脚注 `[^1]`（gfm schema + 自研输入规则：行内引用原子化、`[^1]: ` 定义转换、定义块段尾 Enter 退出）、高亮 `==文本==`、上下标（`^x^`/`~x~` 与 `^{x}`/`_{x}` 两种写法均识别，保存统一为 Pandoc 单符号风格）、YAML front matter（文档开头 `---` 围栏在所见即所得中渲染为键值属性表，点击进 YAML 文本编辑，非法 YAML 提示并保留原文，保存字节级原样写回；导出 HTML/PDF 时自动剥离）。快捷键：高亮 Cmd/Ctrl+Shift+H、上标 Cmd/Ctrl+Shift+=、下标 Cmd/Ctrl+Shift+-，格式菜单同步
- [x] 图床上传：集成 PicGo-Core（在主进程运行，渲染层零 Node 权限），内置 SM.MS / GitHub / 七牛云 / 又拍云 / 腾讯云 COS / 阿里云 OSS / Imgur 共 7 种图床，设置面板选类型填参数即可；上传失败自动降级内联，配置文件存 userData 目录（随卸载清理）
- [x] 快捷键自定义：设置面板按「文件 / 导出 / 格式 / 编辑器」四组罗列 31 项，点击按键框后按下新组合键即可改键；带冲突检测与就地错误提示、一键恢复默认；主进程菜单 accelerator 与编辑器 keymap 读同一份配置，改键即时生效
- [x] 跨文件全文搜索：在侧边栏已挂载的文件夹中逐行检索（Ctrl/Cmd+Shift+F），结果按文件分组显示行号与上下文并高亮关键词，回车打开并定位到匹配处；扫描在主进程执行，跳过依赖目录、限制单文件 2MB / 扫描 5000 文件 / 命中 500 行，超限标记截断
- [x] 导出 Word / 长图：Word 生成原生可编辑 .docx（标题、段落、列表、表格、行内格式、超链接均为 Word 原生元素；独占公式与 Mermaid 图表以 2x 位图嵌入保真），长图导出为单张 2x 清晰度 PNG（超长文档自动分段拼接，整图上限约 60000 原始 CSS px）；两者经隐藏窗口离屏渲染（Mermaid/KaTeX 本地离线渲染），入口在主菜单「导出」与工具栏 ⋯ 菜单，不绑快捷键
- [x] ~~PlantUML 等其他图表语言~~ → 决策不做：PlantUML 无成熟的纯前端离线方案（WASM 端口不成熟、打包 Java 太重），与 TMD 轻量离线定位冲突。参考 Typora/iA Writer/Zettlr 等同类工具均不支持。如需 PlantUML，用专门工具画图后导出 PNG 粘贴进 TMD
- [x] 本地历史版本：每次写盘前自动留存被覆盖的旧内容（`~/.tmd/history`，按文件分目录、文件名即时间戳，内容未变不重复留档，每文件 50 条 + 全局 200MB 自动清理）；主菜单「文件 → 历史版本…」列出快照、预览并恢复到编辑器，恢复只改编辑器内容并置脏、不直接覆盖磁盘
- [x] 左右分屏：源码与所见即所得并排（悬浮菜单（⋯）→「分屏」/ Cmd/Ctrl+Shift+E），一侧编辑、另一侧只读跟随（点哪一侧即可编辑那一侧），滚动近似同步，中间分隔条可拖拽调宽且宽度持久化；分屏中切换标签保持分屏状态
- [x] 设置面板双栏改版：弹窗加宽为「左侧分类导航 + 右侧内容」（外观/排版/编辑器/文件与图片/快捷键/系统/关于 七类），点击定位、滚动高亮跟随，13 个区块按类重排；主题选择改色卡预览、界面语言改胶囊选项、第三方许可证列表折叠、按钮统一；新增文件菜单「设置…」与 `Cmd/Ctrl+,` 入口（平台惯例键位，不进自定义快捷键表）

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 中文输入法 | 编辑器所有交互路径下 IME 组合输入正常（光标不跳、不丢字）——开发期持续用中文输入法测试 |
| 性能 | 1 万字 + 10 个 Mermaid 图的文档，输入无可感知卡顿（<16ms 帧预算按块增量渲染） |
| 大文档（实测） | 1MB / 6952 段纯文本：打开 474ms、滚动稳定 60 FPS、单次输入同步约 21ms（主因是入库前全文重新序列化，受上游限制）；30 张 Mermaid 图按**视口懒渲染**（未滚动只渲染视口内图表，滚动按需补渲）；`npm run bench` 可复跑并带回归门禁 |
| 跨平台 | Mac 与 Windows 行为一致（Electron 保证内核一致，需统一快捷键差异，如 Cmd/Ctrl） |
| 安全 | Mermaid `securityLevel: 'strict'`；渲染 HTML 过滤 XSS；主进程注入 CSP 头（`default-src 'self'`、`script-src 'self'`，禁 eval/内联脚本） |
| 大文件 | 100KB 以上文档打开时间 < 2s |
| 可靠性与可观测 | crashReporter 本地落盘（`~/.tmd/crash-dumps`），**零遥传**：不上传、无服务端、无崩溃弹窗；主/渲染进程 JS 异常与子进程崩溃统一写本地 JSONL 日志（`~/.tmd/logs`，7 天/10 文件滚动），设置面板可打开日志文件夹；资产根支持 `TMD_HOME_DIR` 重定位 |
| E2E 回归 | 桌面主链路（打开/编辑/保存/另存为/崩溃恢复）与导出链路有可复跑的真实产物 E2E（`npm run test:desktop`），不引入额外测试框架 |
