## Context

v0.2.1 已完整发布（Rust 0.2.1 + Electron 0.1.8 并存，迁移提示已开启），双轨过渡的目标已达成。用户决定 **Electron 架构全面下线**：删除壳层代码、停止构建 Electron 包。0.1.x 老用户的迁移路径（0.1.6 → 自动更到 0.1.8 → 弹迁移框 → 手动下载 Rust 版）必须继续可用，依赖的是**冻结的元数据**（`releases/latest*.yml` 指向 0.1.8、`migration.json` 指向 0.2.1）而非 Electron 构建。

已确认决策：彻底删除代码（git 历史可恢复）；本次不发版，下次 Rust 发版自然生效。

## 改动清单

### 1. 删除 Electron 壳层与测试
- `electron/` 目录整体删除（27 个 .cjs）
- `src/__tests__/` 中 19 个 require electron 模块的测试删除：updater-migration、ipc-sender-guard、ipc-files、ai-ipc、ai-client、ai-config、app-state、menu、dirwatcher、filewatcher、fsops、history、logger、text-file、themes、wikilinks、pdf-options、exporter、dmg-ulmo（共删约 19 个文件；extract-release-notes.test.ts **保留**——测的是双轨共用脚本）
- `build/` 目录删除（icon.*、installer.nsh 仅 electron-builder 消费）

### 2. package.json
- 删 `"main"` 字段、整个 `"build"` 段（electron-builder 内嵌配置）
- 删 deps：`electron-updater`、`picgo`、`iconv-lite`；删 devDeps：`electron`、`electron-builder`、`concurrently`、`wait-on`
- 删 scripts：`dev:electron`、`test:desktop`、`bench`、`dist`、`dist:dir`、`dist:install`、`icon`
- 保留：`notes`（GitHub/Gitee Release 说明共用）、`build`/`test`/`tauri` 系全部、`cleanup`
- 跑 `npm install` 刷新 package-lock

### 3. scripts/ 删除
- Electron 专属：`make-dmg-background.mjs`、`patch-mac-dmg.mjs`、`trim-runtime.cjs`、`make-icon.mjs`、`desktop-app-check.mjs`、`desktop-export-check.mjs`、`desktop-bench.mjs`、`lib/desktop-harness.mjs`
- 保留：`extract-release-notes.mjs`、`prepare-gitee-release.mjs`（本地通道仍从 GitHub Release 拉冻结 yml）、`make-migration-json.mjs`、`make-tauri-latest.mjs`、`copy-export-assets.mjs`、其余 Tauri 工具

### 4. 配置清理
- `tsconfig.json`：include 删 `electron`
- `eslint.config.js`：删 electron CommonJS override 块
- `.npmrc`：删 electron_mirror 行

### 5. CI（.github/workflows/release.yml）
- 删 `build` job（Electron 线）与顶层 `ELECTRON_VERSION`、`MIGRATION_TARGET` env
- publish job：`needs` 改为 `[build-tauri]`、if 简化；删 `download-artifact release-*`（Electron artifacts）；删 dmg background / ULMO 后处理（随 build job 已删）
- `Make migration.json`：改为**无条件生成**，`--version` 取 package.json version（0.1.8 用户永远被引导到最新 Rust 版；0.1.x 清零后删除该步骤即可，注释写明）
- **冻结元数据续传**：publish job 加一步 `cp releases/latest.yml releases/latest-mac.yml release/`，使每个新 GitHub Release 仍带 0.1.8 的 latest*.yml——保证 electron-updater 的 GitHub 备用源（`releases/latest/download/latest.yml`）在 v0.2.2 成为 latest 后仍返回冻结内容
- `prepare-gitee-release.mjs --local` 调用删除（无新 yml 输入，脚本会 throw）；Gitee 元数据推送改为直接用仓库 `releases/` 冻结副本 + CI 新生成的 latest.json/migration.json（`git diff --cached --quiet` 无变化跳过逻辑天然兼容）
- 上传/校验通配符：删 `release/*.blockmap`、`release/latest*.yml` 依赖构建产物的部分（yml 由冻结副本 cp 提供，保留在通配符中）；`*.exe`、`*.dmg` 保留（Tauri NSIS/dmg 仍走这些通配）
- 配额清理加 `MIGRATION_KEEP_TAG: v0.2.1` 锚点：清理循环跳过该 tag 的 Release——**保护老用户链路**（冻结 yml 与 migration.json 都指向 v0.2.1 的 Gitee 附件，被清理即断裂）；迁移期结束删此 env

### 6. 注释与文档
- `src-tauri/src/` 7 个模块的「JS 版保留服务 Electron 壳，需两处同步」注释（wikilinks/logger/history/themes/watcher/export_assets/fsops）改为「Electron 壳已下线（git 历史可查）」；`main.rs` 头注释删「双壳共存」与过期 identifier；`window.rs` 标题注释删 Electron 对比；`tmd-api-shim.js` 的 Electron 对照注释酌情精简

- `CHANGELOG.md` Unreleased 加「移除」段：Electron 壳层代码删除、CI 停发 Electron 包、老用户迁移路径冻结说明

### 7. 不动的东西（明确边界）
