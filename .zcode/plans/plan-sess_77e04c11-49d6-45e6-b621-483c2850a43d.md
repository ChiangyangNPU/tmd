# 图谱对齐 Obsidian 实施计划

**决策基线**:局部图谱做侧边栏迷你力导向图;全库图谱保持模态弹窗(内部功能对齐);按文件夹着色;拖拽即固定(双击解钉)。共 3 个提交,每提交即 pushall。

## Phase 1 全库图谱对齐(改 src/graph.ts + graph.html + 新增设置持久化)

面板头部加**齿轮按钮**,点开设置弹层(面板内浮层,非浏览器弹窗),含以下控制(持久化到 localStorage `tmd:graph-settings`,经 store.ts 模式新增读写函数):

1. **幽灵节点**:未解析的 `[[目标]]` 以虚拟节点入图——空心圆 + `--muted` 虚线描边,标签即目标名;默认显示,开关可关。点击幽灵节点维持现有 toast 提示。
2. **方向箭头**:边的 target 端绘制小三角箭头(起点从源节点圆边缘出发,箭头落在目标圆边缘前),默认显示,开关可关。
3. **孤立笔记开关**:degree=0 的节点默认显示,可隐藏。
4. **搜索过滤**:设置弹层内输入框,按笔记名/路径子串实时过滤——**匹配节点正常,非匹配节点淡化**(20% 透明,仍占位,与 Obsidian 一致)。
5. **力参数滑杆**:斥力(-200~-50,默认 -140)、连线距离(20~200,默认 60)、居中力(0~100%)——拖动即更新 sim 配置并 alpha reheat。
6. **按文件夹着色**:节点颜色 = 所属挂载根文件夹 → 内置色板(6 色循环,中饱和度保证深浅主题可读);不属任何文件夹的笔记用前景色;默认开,可关。
7. **拖拽固定**:pointerup 后保留 fx/fy(节点钉住);**双击节点解除固定**;设置弹层加「重置布局」按钮(清除全部钉住 + 重跑模拟)。

实现要点:graph.ts 重构出「设置状态(模块级 + 持久化)」与「图数据构建(节点集 = 笔记 + 幽灵;过滤/着色/邻居计算为导出纯函数供单测)」;设置变更路径统一为「更新 sim 配置 + alpha(0.5) reheat + scheduleDraw」。

## Phase 2 局部图谱侧边栏面板(新增 src/local-graph.ts + 模板/接线)

1. **侧边栏第三面板「关系」**:index.html 在 files-panel 后加 `relations-panel`;`toggleSidebar` 扩展三态(`'outline' | 'files' | 'relations'`,互斥显隐逻辑照旧);入口 = ⋯ 菜单「局部图谱」按钮 + 命令面板(不占快捷键)。
2. **邻居数据**:
   - 一跳出链:**实时**从 `currentMarkdown()` 正则解析 wikilink(未保存的新链接即时可见,不等待保存);
   - 一跳反链:双链索引中 `resolved.path === 当前笔记` 的来源;
   - 二跳(可切换):一跳邻居再按索引扩展一层,去重;
   - 未解析目标也入图(幽灵节点,同全库规则)。
3. **渲染**:面板内小 canvas(宽随侧边栏 180–480px,高 260px),d3-force 迷你模拟(参数按小尺寸调低);节点色 = 文件夹着色同款规则,当前笔记节点 accent 色放大。
4. **交互与刷新**:悬停高亮邻居;点击节点 `openPath` 跳转;**刷新时机** = 活动标签切换 + `onWikiIndexRefreshed` + 面板打开时;面板头提供 **1 层 / 2 层** 切换与当前笔记名显示;未保存文档提示先保存(与反链面板同款空态)。
5. 复用:`getWikiLinks`、`resolveWikiTarget`、`normalizeForDirtyCompare` 无关不用;着色函数与全库共用(从 graph.ts 导出)。
